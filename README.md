## 📝 Basic Usage Examples

RYN27 works through command line instructions that you type after launching the program.

Here are some simple commands to try:

- To get WHOIS data for a website:  
  `ryn27 whois example.com`

- To find DNS records for a domain:  
  `ryn27 dns example.com`

- To check geolocation of an IP address:  
  `ryn27 geo 8.8.8.8`

- To scan ports on a host:  
  `ryn27 ports example.com`

- To detect web technologies used by a site:  
  `ryn27 tech example.com`

Replace `example.com` or `8.8.8.8` with the site or IP you want.

## ⚙️ Common Commands and Options

RYN27 includes several commands. Each has options to customize its behavior.

| Command | Purpose                           | Example                       |
|---------|---------------------------------|------------------------------|
| whois   | Get domain registration details | `ryn27 whois example.com`    |
| dns     | Query DNS records                | `ryn27 dns example.com -t MX`|
| geo     | Locate an IP address             | `ryn27 geo 1.1.1.1`          |
| ports   | Scan open ports on a target     | `ryn27 ports example.com`    |
| tech    | Detect website technologies     | `ryn27 tech example.com`     |

Use `ryn27 help` to see a full list of commands and options.
